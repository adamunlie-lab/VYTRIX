1. WHAT VYTRIX DOES

VYTRIX is a Windows optimization utility. When you ask it to, it can
change Windows settings, including registry values, power plans, DNS
servers, startup entries, Windows service startup types and temporary
files. Each control describes what it changes, and tweaks, profiles,
DNS, service and cleanup actions ask for confirmation first
(confirmation for low-risk tweaks can be turned off in Settings). Changes to
machine-wide settings require administrator rights, which Windows asks
you to grant.

4. BACKUPS, ROLLBACK AND THEIR LIMITS

VYTRIX records the previous value of every setting it changes, exports
registry backups, and can create Windows System Restore points. These
features are provided to help you undo changes. However:

  (a) Some actions cannot be reversed. These include deleting temporary
      files, emptying the Recycle Bin, ending a running app (unsaved
      work in it is lost) and resetting Winsock. VYTRIX asks for
      confirmation first and records these in the journal as not
      reversible.
  (b) Rollback restores the values VYTRIX recorded. If other software,
      Windows Update or you change the same setting afterwards, rollback
      may overwrite that later change.
  (c) Windows may skip creating a restore point if one was created in
      the last 24 hours, or if System Protection is turned off. VYTRIX
      reports when this happens.
  (d) Before uninstalling, use Restore Center > "Roll back everything"
      if you want Windows returned to its previous configuration.
      Uninstalling does not undo changes on its own.
